# open-news-dashboard
Ziel: 
Ein trackerfreies, werbefreies, transparentes News-Dashboard, das verschiedene politische Perspektiven nebeneinander sichtbar macht.

Philosophie dahinter: 
Jeder Mensch sollte den Zugang zu freien, jedoch leicht eingeordneten News haben.

Warum es existiert: 
Ich war auf der Suche nach einer Art freien unabhängigen Medien die wirklich keinen monetären Nutzen oder Daten daraus ziehen. 
Fündig wurde ich bei FreshRSS, parliament, news-balancer und Crux-News, jedoch hätte auch gerne ähnliche Features wie Parliament aber besser dargestellt wie in CruxNews-OpenNews.

Warum ich es versuche/tue:
1.Tech-Stack 
2.UI-Design lernen und verstehen
3.Linux lernen
4.erstes Self-hosting Projekt in Kombination mit anderen Implementationen
